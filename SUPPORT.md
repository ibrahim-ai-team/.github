# Support

## Where to ask for help

- **How-to questions and usage help:** open a discussion or issue in the repository that owns the relevant tool or workflow, if that feature is enabled there.
- **Bug reports:** open an issue in the affected repository with steps to reproduce, expected behavior, actual behavior, and relevant version/environment details.
- **Feature requests:** describe the user problem, expected outcome, constraints, and acceptance criteria in an issue.
- **Organization profile or repository-structure questions:** open an issue in [ibrahim-ai-team/.github](https://github.com/ibrahim-ai-team/.github).
- **Security vulnerabilities:** follow [SECURITY.md](SECURITY.md); do not post sensitive details publicly.

## Helpful issue details

Please remove secrets and personal data before sharing logs or screenshots. Include minimal reproducible examples and distinguish observed facts from assumptions.

This is a community project maintained with limited capacity. Support is best-effort; no response time or resolution is guaranteed.
